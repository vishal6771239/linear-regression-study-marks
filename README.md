# linear-regression-study-marks
Linear Regression project - Study Hours vs Marks prediction using Scikit-learn

## What I did
- Learned Linear Regression concept from scratch
- Calculated m, b, MSE by hand
- Used Scikit-learn to verify results

## Dataset
- Students study hours vs marks
- 5 students data

## Results
- m (slope)     = 13.50
- b (intercept) = 6.50
- MSE           = 1.50
- 6 hours prediction = 87.5 marks

## Formula
y = mx + b
y = 13.50x + 6.50

## Tools Used
- Python
- Scikit-learn
- NumPy
- Google Colab
